Questions

Is it really free?

Yes. No money, no sign-up, and all of the source code is public.

Can I sell music I make with flipper?

Yes. The sounds and songs you make are yours. The licence covers the plug-in program, not what you make with it.

Will it run on my computer?

On Macs with Apple Silicon or Intel, and on 64-bit Windows 10 and 11. Not on ARM Windows yet.

Which DAWs?

Any DAW that opens AU or VST3 plug-ins. Checked in Logic Pro, REAPER and Cubase.

Anything to know about the beta?

macOS asks you to allow it once the first time; on Windows, click 'More info → Run anyway' in SmartScreen. When a new version is out, a dot lights up by the plug-in's logo.

Where is the source code?

On GitHub. The code we wrote is MIT; the plug-in we ship is AGPL-3.0 because of the libraries bundled with it.
