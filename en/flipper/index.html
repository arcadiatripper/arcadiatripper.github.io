001 / SCREENS

Three screens

sampler

Drop a sample, tap along while it plays, and it chops where you tap. The slices go straight to the pads: play them as pads or as a melody.

drum

A 16-cell drum kit. Each cell has its own engine, trims and effects, and 16 outputs send them apart to your DAW. Kits save as .flipkit files.

fx

Grab the record and scratch. An effect rack from filter to echo, fx pads, scratch patterns and a fader, all on one screen.

002 / ENGINES

Change the engine,
change the sound and the look

Four engines. Each one changes the grain of the sound, and the screen changes into that engine's clothes. Each machine engine has its own filter, drive and record speed (33 · 45 · 78).

CLEAN · THE SAMPLE AS IT IS

The sample as it is. Stays clear however far you stretch it.

BLACK · 12-BIT · 26 kHz

Gritty and dark: the grain of a late-80s 12-bit sampler.

GREY · 12-BIT · 40 kHz

Tight and warm: the grain of a late-80s 12-bit sampler.

PURPLE · 4-BIT · 32 kHz

Soft and muffled: the 4-bit sound of an early-90s console.

003 / KEY & TEMPO

Pitch it down,
it tells you the tempo

In repitch mode, key and speed move together. Producers used to match it by ear against a metronome; flipper shows the BPM it lands on. In keep-tempo mode, key and tempo change apart.

You get 89.9 BPM

004 / MORE

And also

  • Lazy chop

005 / INSTALL

Install

Mac

  • macOS, Apple Silicon and Intel (universal)
  • AU (Logic Pro and others) · VST3
  • The beta isn't signed by Apple yet, so macOS may block it the first time. Allow it once as the guide shows.

Windows

  • 64-bit Windows 10 · 11 (no ARM laptop build yet)
  • VST3
  • If SmartScreen warns you, click 'More info → Run anyway'.

Checked in Logic Pro, REAPER and Cubase. Most other DAWs that open AU or VST3 work too.

006 / BETA

It's a beta

Bug report

If something looks wrong, tell us with the bug report key at the bottom right of the plug-in. No name or account needed.

Update notice

When a new version is out, a small dot lights up by the logo. Click it to go and get it.

Nothing sent

The plug-in sends no usage data. A bug report goes out only when you press send and agree.

007 / FAQ

Questions

Is it really free?

Yes. No money, no sign-up, and all of the source code is public.

Can I sell music I make with flipper?

Yes. The sounds and songs you make are yours. The licence covers the plug-in program, not what you make with it.

Will it run on my computer?

On Macs with Apple Silicon or Intel, and on 64-bit Windows 10 and 11. Not on ARM Windows yet.

Which DAWs?

Any DAW that opens AU or VST3 plug-ins. Checked in Logic Pro, REAPER and Cubase.

Where is the source code?

On GitHub. The code we wrote is MIT; the plug-in we ship is AGPL-3.0 because of the libraries bundled with it.
